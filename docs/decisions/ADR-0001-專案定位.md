# ADR-0001：CVE2Action 的專案定位

- 狀態：Accepted
- 日期：2026-09-15
- 決策者：Tsai Lisp

## 背景

既有弱點掃描產品擅長發現漏洞，但產出通常以 CVE 與 CVSS 為中心，難以直接回答企業應先修哪一個漏洞、漏洞是否位於可利用的入侵路徑，以及既有控制是否已降低風險。

## 決策

CVE2Action 定位為「弱掃後的風險與修補決策引擎」：

1. 接收既有弱掃結果，不主動掃描或入侵任何系統。
2. 結合公開威脅情報、資產重要性、暴露面、拓樸、權限關係與補償性控制。
3. 輸出可解釋的修補優先序、攻擊路徑、建議措施及措施前後差異。
4. 核心分數採確定性公式，LLM 僅能協助文字說明，不參與分數計算。

## 理由

- 符合 30 天可完成、可展示、可驗證的範圍。
- 避免把時間消耗在掃描器協定、Agent 或漏洞驗證技術。
- 能直接呈現企業 Infrastructure 與 Vulnerability Management 的實務價值。
- 方便使用完全虛構的資料公開專案，不暴露公司資訊。

## 不在範圍內

- Port Scan、弱點探測或 Exploit 執行。
- 真實企業的 IP、主機名稱、拓樸、弱點與帳號資料。
- 以分數取代資安、系統負責人及變更管理的人工判斷。
- 建立精確財務損失或事件發生機率模型。

## 後果

優點是範圍清楚且成果容易重現；限制是輸出品質取決於輸入的資產、拓樸與控制資料完整度。系統必須顯示資料缺口與信心程度，不能把未知資料自動視為低風險。
