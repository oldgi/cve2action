# CVE2Action v1.0.0

> 弱掃告訴我們哪裡有洞；CVE2Action 告訴我們攻擊者可能從哪裡進來、會走到哪裡，
> 以及現在先做哪一件事最划算。

![demo](../images/demo/demo.gif)

## 怎麼跑

```bash
docker build -t cve2action .
docker run --rm -p 8501:8501 cve2action                  # 儀表板 http://localhost:8501
docker run --rm cve2action uv run --no-sync pytest -q    # 全部測試
```

不用 Docker：`uv sync --extra dashboard`，然後 `uv run --extra dashboard streamlit run app/dashboard.py`。
全部離線；NVD／EPSS／KEV 是 `data/snapshots/` 裡帶日期的固定快照。

## 已知限制

1. **攻擊圖不看漏洞**，所以 patch 切不掉路徑（ADR-day-27）。
2. **頂端沒有鑑別力**：前十名的業務衝擊全是 CRITICAL、威脅全在 KEV；24/40 是 P0（ADR-day-29）。
3. **兩條評分門檻未過**：`band_balance` 0.5263、`range_coverage` 0.443；2026-11-12 再檢視（ADR-day-28）。
4. **處置清冊照弱點登記**：29/40 沒有候選措施；Day 24 的三個瓶頸沒有任何措施（ADR-day-26、27）。
5. **人工基準只有 5 筆、排序者即作者**：τ-b 0.6 對 CVSS 0.527 是自我一致性，不是證據。
6. **沒有「可解析的最小差距」**：只標完全同分。
